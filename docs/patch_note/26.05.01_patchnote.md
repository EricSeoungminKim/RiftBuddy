# 26.05.01 Patch Note

## Backend

- Added Groq and Gemini LLM provider support.
- Added mock LLM mode for free/local testing.
- Added richer Riot Live Client context:
  - champion name
  - summoner name
  - game mode
  - CS
  - KDA
  - ward score
  - items
  - summoner spells
  - recent events
- Improved Riot Live Client reliability by disabling proxy env usage for localhost polling.
- Added configurable ElevenLabs model ID.
- Added safer TTS error handling so text advice still appears when voice output fails.
- Added local auth bypass flag for real-service testing without Supabase login.
- Added Korean-only response prompting and post-processing for common mixed English terms.
- Added optional wake word pipeline:
  - English wake phrase detection.
  - Korean question transcription after wake.
  - Siri-style flow: wake -> "네?" -> listen until silence -> answer -> return to standby.
- Split STT settings for wake detection and question recognition:
  - wake model/language
  - question model/language
- Added silence detection settings for post-wake question capture.
- Added active WebSocket client tracking so wake-word results can be broadcast to the overlay.
- Added transcript/listening events so the UI can show when the assistant heard the wake word and when it is waiting for the user's question.

- Added chat-style overlay messages:
  - `USER: ...`

- Added auto-scroll and taller overlay chat panel.
- Added frontend root `.env` loading through Vite config.
- Added default root `.env` WebSocket support for `VITE_RIFTBUDDY_WS_URL`.
