# 26.05.02 Patch Note

## Draft Window — New Features

- Added LCU champion select auto-detection via `/lcu/champ-select/status` polling (2.5-3s interval depending on Electron/frontend path).
- Draft Window now auto-populates ally and enemy slots from League client during real champion select.
- Added Korean → English champion name mapping (172 champions, DDragon 16.9.1).
- Auto-navigates to Post Lock-In page when all 10 picks are confirmed by LCU.
- Added inline enemy champion input UI — replaces broken `window.prompt` (which returns null in Electron renderer).
- Enemy slot now highlights on click with red border input row, matching ally slot behavior.
- Added op.gg MCP analysis panels: champion analysis, lane matchup, team synergy.
- Added rune application via LCU (`/lcu/apply-runes`).
- Added tab cycling hotkeys: `Cmd/Ctrl+Shift+]` (next), `Cmd/Ctrl+Shift+[` (prev) — replaces Cmd+Shift+1-5 which conflicted with macOS system shortcuts.
- Added cell-aware LCU draft slot sync:
  - `/lcu/champ-select` now returns `allySlots` and `enemySlots` with `cellId`, slot index, champion, completed state, and assigned position.
  - Draft UI now maps champions by LCU slot/cell instead of guessing from completed-pick order.
  - Hovered picks are shown as tentative slots while locked picks are used for final ally/enemy arrays.
- Added quiet LCU polling endpoint:
  - `/lcu/champ-select/status` returns `200 OK` with `available: false` when League client is not open.
  - Electron and Draft UI now poll the status endpoint instead of repeatedly hitting `/lcu/champ-select` and producing expected `503` logs.
- Added real-time matchup analysis per lane pair in Draft Window.
  - When both ally and enemy slots are known, the UI automatically requests op.gg matchup data.
  - Matchup panel shows win rate/pick rate/advantage when available from the MCP payload.
- Draft Window now detects the local player's `myCell` and selects the player's slot/role automatically.

## Bug Fixes

- Fixed `myTeam` set being rebuilt inside inner loop during champ-select parsing — caused wrong ally/enemy classification when `myTeam` was absent during ban phase.
- Fixed auto-navigate firing on hovered/tentative picks — now only triggers on `completed: true` locks from LCU and only when `champSelect.inProgress` is active.
- Fixed `window.prompt` for enemy champion input — broken silently in Electron (returns null), replaced with inline input component.
- Fixed Korean `.lower()` fallback in `_normalize_champion` — dead code (Hangul has no case), removed. English names from LCU DDragon now handled correctly in the else branch.
- Fixed op.gg MCP API parameter names: `champion_name` → `champion`, `enemy_champion_name` → `opponent_champion`, added required `game_mode: "ranked"` and `desired_output_fields`.
- Fixed position mapping: `"바텀"` / `"bottom"` → `"adc"` to match op.gg API enum.
- Fixed `useDraftAnalysis` / `usePostGame` / `DraftApp` using wrong port (`8765`) — updated to `VITE_RIFTBUDDY_API_URL` env var (default `http://localhost:8001`).
- Removed `import platform` (unused) from `backend/lcu/router.py`.
- Removed redundant `runes:` cache layer in `get_runes` — `get_champion_analysis` already caches the full response.
- Fixed a fragile draft slot bug where enemy/ally picks could shift into the wrong role because only completed champion arrays were sent to the frontend.
- Fixed manual wake-word test script importing audio dependencies during pytest collection.
- Updated `Command/Ctrl + Shift + B` planned prompts to include role, KDA, CS, held gold, health, and time instead of only global gold status.
- Removed pytest warning noise:
  - migrated FastAPI startup/shutdown from deprecated `@app.on_event` handlers to lifespan.
  - renamed `test_app` fixture-like module variable so pytest no longer tries to collect it as a test.
- Fixed LCU route integration test isolation so local League client state cannot cause flaky `apply-runes` results.

## Backend

- DDragon version now fetched dynamically from `https://ddragon.leagueoflegends.com/api/versions.json` — no longer hardcoded to a specific patch. Champion ID map cached in-process so DDragon is not called on every poll.
- LCU champ-select data now separates strict completed-pick arrays from richer slot state:
  - `ally` / `enemy` contain completed picks.
  - `allySlots` / `enemySlots` preserve hover/tentative champions, completed state, assigned position, and `cellId`.
- Added `KO_TO_EN` mapping for 172 champions (DDragon 16.9.1), including newest: 암베사 (Ambessa), 오로라 (Aurora), 멜 (Mel), 유나라 (Yunara), 자헨 (Zaahen).
- Planned advice question generator now prioritizes concrete local state:
  - low HP + high gold
  - high held gold
  - jungle route/gank/objective decision
  - low CS / wave state
  - support vision
  - ahead/behind gold with specific risk/play framing

## Notes

- LCU auto-detection only opens the Draft Window during real champion select (normal/ranked/ARAM draft). Queue alone does not open it.
- `/lcu/champ-select/status` is the poll-friendly endpoint:
  - League closed: `200 OK`, `available: false`, `inProgress: false`
  - League open but not in champ select: `200 OK`, `available: true`, `inProgress: false`
  - Champ select active: `200 OK`, `available: true`, `inProgress: true`
- `/lcu/champ-select` remains the strict debug endpoint and can still return `503`/`404` when League or champ select is unavailable.
- op.gg MCP `desired_output_fields` parameter behavior depends on op.gg's MCP server implementation — if ignored, full payload is returned (safe fallback).
- In-game overlay is now configured closer to Blitz/op.gg style:
  - Electron overlay uses panel mode, screen-saver always-on-top level, click-through, non-focusable mode, and transparent document background.
  - Overlay follows the League window bounds every 2 seconds.
  - If League uses exclusive fullscreen, OS-level overlay behavior may still require borderless/windowed fullscreen.
- Backend test suite now runs cleanly with no pytest warnings: `62 passed`.
