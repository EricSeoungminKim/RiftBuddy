# Phase 3.5: Dynamic Performance-Based Seed Generation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Automatically generate personalized RAG seeds from real game performance data (KDA, CS, gold diff) at game end, so the coaching system improves with each game played. Static champion knowledge from Phase 3 remains the fallback when no personal history exists.

**Your idea:** Play RiftBuddy → game ends → performance data is auto-collected → seeds are added to ChromaDB → next game retrieval includes your personal coaching history alongside static champion tips.

**Architecture:**
```
Game in progress → GameSession collects snapshots (already works)
                          ↓
              Game end detected (game_end event in main.py)
                          ↓
         PerformanceSeedGenerator reads GameSession.snapshots
                          ↓
         Extracts: champion, KDA, CS, gold_diff, key_moments
                          ↓
         Generates coaching seed text → embeds into ChromaDB
                          ↓
         Next game retrieval: static seeds + personal history seeds
```

**Key insight:** `GameSession` already captures all needed data (kills/deaths/assists, creep_score, gold_diff, champion_name, game_time snapshots). No new data collection needed — just a generator that reads `game_session.snapshots` at game end and writes seeds.

**Fallback strategy:** If no personal seeds exist for a champion, retriever returns only static seeds from Phase 3. No error, no degraded experience.

**Tech Stack:** Extends existing ChromaDB collection from Phase 3 (`backend/knowledge/embedder.py`), new collection namespace `performance_seeds`, Python 3.13, pytest.

- [ ] **Step 2: Create `backend/knowledge/performance_seeds.py`**

  ```python
  # backend/knowledge/performance_seeds.py
  from __future__ import annotations
  from dataclasses import dataclass
  from datetime import datetime
  from typing import TYPE_CHECKING
  import chromadb

  if TYPE_CHECKING:
      from backend.game_session import GameSession

  COLLECTION_NAME = "performance_seeds"


  @dataclass
  class GameSummary:
      champion: str
      kills: int
      deaths: int
      assists: int
      avg_cs: float
      avg_gold_diff: float
      game_duration_minutes: float
      key_moments: list[str]


  def summarize_session(session: "GameSession") -> GameSummary | None:
      """Extract final stats from snapshots. Returns None if session is empty."""
      ...


  def generate_seed_text(summary: GameSummary) -> str:
      """Convert GameSummary into a natural-language RAG seed string."""
      ...


  def embed_performance_seed(
      collection: chromadb.Collection,
      summary: GameSummary,
      seed_text: str,
  ) -> str:
      """Embed seed into ChromaDB. Returns the document ID."""
      ...


  def save_game_seed(session: "GameSession", collection: chromadb.Collection) -> str | None:
      """Top-level: summarize → generate text → embed. Returns doc ID or None if empty."""
      ...
  ```

  **Implementation rules:**
  - `summarize_session`: take the last snapshot for final KDA; average `creep_score` and `gold_diff` across all snapshots; compute game duration from last snapshot's `game_time`; identify key moments: any snapshot where `deaths` jumped (death occurred), any 3-snapshot window with highest CS gain, timestamp when `gold_diff` peaked
  - `generate_seed_text`: produce a single string like: `"Personal history - Rumble: 8/3/5 KDA, avg 142 CS, avg +450 gold lead. Strong laning phase. Died at 12:30 and 18:45 - likely overextended after winning trades. Best CS window: 8-12 min."`
  - `embed_performance_seed`: use `collection.add(documents=[seed_text], ids=[doc_id], metadatas=[{...}])` where `doc_id = f"perf_{champion}_{timestamp}"` and metadata includes `champion`, `kills`, `deaths`, `assists`, `avg_cs`, `avg_gold_diff`, `source: "performance"`, `date`
  - `save_game_seed`: call summarize → generate → embed; return `None` if `session.is_empty`
